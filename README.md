# mattiapzz.github.io

Personal website of Mattia Piazza — PhD researcher in optimal control and motion
planning for autonomous and racing vehicles, University of Trento.

Built with [Quarto](https://quarto.org). Published automatically to GitHub Pages
(`gh-pages` branch) via `.github/workflows/quarto-deploy.yml` on every push to `main`.

## Local development

```sh
quarto preview
```
